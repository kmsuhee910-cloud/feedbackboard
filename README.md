# 피드백보드

연한 네온 초록 팔레트의 도트 전시 방명록. 외부 라이브러리·폰트·추적 스크립트 없이 작동하는 정적 웹사이트입니다. 특정 게임의 원본 이미지나 캐릭터를 사용하지 않고 직접 만든 도트 형태와 작품 샘플을 사용합니다.

## 사용

전시 맵의 네 방을 클릭하면 작품과 해당 방의 감상을 볼 수 있습니다. 하단 입력창은 현재 방에 감상을 남깁니다. 전체 지도에서는 전시 전체에 감상을 남깁니다. 다섯 캐릭터의 말풍선은 모든 방의 감상에서 5초마다 바뀝니다. 샘플 감상은 방 안에서 표시되며 내보내기에는 포함되지 않습니다.

**현재 저장 방식은 기기별 localStorage입니다. 서로 다른 기기의 방문자가 입력한 글은 공유되지 않습니다.** GitHub Pages는 정적 호스팅이므로 실제 공동 방명록에는 별도의 데이터베이스/API가 필요합니다. 이 버전은 전시용 단일 키오스크 또는 시연에 바로 사용할 수 있습니다. 같은 브라우저의 탭 사이에는 저장한 글을 동기화합니다. 최대 500개를 저장하며 이후 가장 오래된 글부터 제외됩니다. 중요한 기록은 하단 내보내기 버튼으로 보관하세요. 브라우저 데이터 삭제 시 기록도 삭제됩니다.

## 로컬 실행

이 폴더에서 `python3 -m http.server 8080`을 실행하고 `http://localhost:8080`을 방문하세요. 종료는 Ctrl+C입니다.

## GitHub Pages 배포

1. GitHub에 새 저장소를 만들고 이 폴더의 내용을 저장소 최상단에 넣습니다. `.github/workflows/deploy.yml`도 포함합니다.
2. 기본 브랜치를 `main`으로 사용합니다.
3. 저장소 Settings → Pages → Build and deployment → Source에서 GitHub Actions를 선택합니다.
4. `main`에 푸시하거나 Actions에서 Deploy feedback board를 수동 실행합니다.
5. 배포가 완료되면 Pages에 표시되는 주소를 공유합니다.

Git 명령을 사용하지 않을 경우 `index.html`, `style.css`, `app.js`를 저장소에 업로드한 다음 Pages에서 Deploy from a branch, main, /(root)를 선택해도 됩니다.

## 전시 내용 변경

`app.js`의 `rooms`에서 방 이름·설명·작품명을 변경합니다. `seeds`에서 샘플 감상을 변경하거나 빈 배열로 바꿀 수 있습니다. `style.css`의 `.art-1`~`.art-4`가 샘플 작품입니다. 실제 작품을 사용하려면 로컬 이미지 파일을 추가하고 작품 생성 코드를 변경하세요.

## 보안 및 개인정보

- 입력한 글은 `textContent`로만 표시하여 HTML이나 스크립트로 실행하지 않습니다.
- 메시지는 최대 180자, 이름은 최대 16자로 제한합니다. 로컬 저장 데이터도 읽을 때 검증합니다.
- 외부 네트워크 요청 없이 작동하고 CSP로 외부 연결·인라인 스크립트·객체 삽입 등을 제한합니다.
- API 키·비밀번호·방명록 내보내기 파일을 저장소에 올리지 마세요. 공개 저장소와 배포 파일은 누구나 열람할 수 있습니다.
- 방문객 기록은 암호화하지 않은 브라우저 저장소에 저장합니다. 이름은 별명을 사용하고 연락처 등 민감정보를 입력하지 않도록 안내하세요.
- 제출 간격 제한은 UI 보조 장치이며 서버 수준의 스팸 방지가 아닙니다. 공동 방명록으로 확장할 때는 서버의 입력 검증, 권한, 요청 제한, 신고/삭제 기능 및 보관 정책이 필요합니다.

모바일 레이아웃, 키보드 조작, 동작 줄이기 설정을 지원합니다. 작품과 방 구성은 교체 가능한 가상 전시입니다.
